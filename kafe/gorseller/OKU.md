# Demlik Kahve — Görsel Sözleşmesi

Bu klasöre aşağıdaki dosyaları bırakın. Dosya adları ve en-boy oranları **birebir** uymalı;
`index.html` bu isimleri ve oranları bekliyor — kodda hiçbir satır değişmez.

| Dosya             | Oran       | Ne                                             |
| ----------------- | ---------- | ---------------------------------------------- |
| `hero.jpg`        | 4:3        | Dükkânın önü veya tezgâh, gündüz ışığı         |
| `bento-kahve.jpg` | 1:1        | Filtre kahve demlenirken                       |
| `bento-tatli.jpg` | 1:1        | Günün tatlısı, üstten çekim                   |
| `bento-paket.jpg` | 4:3        | Paket çekirdek, etiketi görünür                |
| `kavurma.jpg`     | 1:1        | Kavurma makinesi veya çekirdek detayı          |
| `og.jpg`          | 1200×630   | Paylaşım görseli (Open Graph)                  |

## Notlar

- Tüm görseller `.jpg` formatında olmalı.
- Fotoğraf yokken sayfa bozulmaz; CSS degrade tutucu ve açıklama metni görünür.
- WhatsApp bağlantısındaki numara yer tutucudur: `905XXXXXXXXX`. Gerçek numarayla değiştirin.
- Telefon numarası `0216 XXX XX XX` biçiminde yer tutucudur.
